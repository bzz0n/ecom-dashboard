# E-Commerce Dashboard

Ein interaktives Dashboard für einen Onlineshop: Umsatz, Bestellungen, Warenkorbwert, Retourenquote, Verkaufskanäle, Kategorien und Top-Produkte, jeweils im Vergleich zum Vorjahr.

Die Daten in `data.js` sind zufällig erzeugte Beispieldaten.

## Öffnen

`index.html` im Browser öffnen. Eine Installation ist nicht nötig.

## Dateien

- `index.html`: Aufbau und Design der Seite
- `data.js`: Beispieldaten (später durch echte Shop-Daten ersetzbar)
- `app.js`: Berechnung der Kennzahlen und Diagramme
